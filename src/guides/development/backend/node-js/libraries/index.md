# Библиотеки

## Настройка среды

- [npm-run-all](https://www.npmjs.com/package/npm-run-all) - инструмент CLI для запуска нескольких npm-скриптов параллельно или последовательно.
- [cross-env](https://www.npmjs.com/package/cross-env) - запуск сценариев, которые устанавливают и используют переменные среды на разных платформах.
- [dotenv](https://www.npmjs.com/package/dotenv) - модуль с нулевой зависимостью, который загружает переменные среды от `.env` в `process.env`.

## Профилирование

- [depcheck](https://www.npmjs.com/package/depcheck) - это инструмент для анализа зависимостей в проекте.
- [node-modules.dev](https://node-modules.dev) - инструмент, позволяющий провести анализ пакета - от чего зависит, какие уязвимости, сколько весит и все такое.
- [knip](https://knip.dev/)
- [unlighthouse](https://www.npmjs.com/package/unlighthouse)

## Локальный сервер

- [json-erver](https://www.npmjs.com/package/json-server) - полный поддельный REST API с нулевым кодированием менее чем за 30 секунд.
- [http-server](https://www.npmjs.com/package/http-server) - инструмент для запуска простого статического HTTP-сервера.
- [js-cookie](ttps://www.npmjs.com/package/js-cookie) - простой и легкий JavaScript API для обработки файлов cookie.

## Работа с пакетами

- [nvm](https://github.com/coreybutler/nvm) - инструмент для контроля версий и переключения между ними
- [fnm](http://github.com/Schniz/fnm) - аналог nvm, написанный на Rust
- [npmx](http://npmx.dev) - современный способ смотреть npm-пакеты

## Прочее

- [bcrypt](https://www.npmjs.com/package/bcrypt) - библиотека, которая поможет шифровать пароли, в соответствии с определёнными стандартами.
- [minimist](https://www.npmjs.com/package/minimist) - инструмент для парсинга аргументов командной строки без всяких причудливых украшений.
