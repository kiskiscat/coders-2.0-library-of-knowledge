# Библиотеки

## Репозитории

- https://unjs.io/
- https://github.com/trekhleb/javascript-algorithms

## Компоненты

- [gridstackjs](https://gridstackjs.com/) - библиотека для создания дашбордов
- [atroposjs](https://atroposjs.com/) - создание красивых паралакс-эффектов
- [driverjs](https://driverjs.com/) - библиотека для туров по продуктам, основных моментов и контекстной помощи
- [shepherdjs](https://www.shepherdjs.dev/) - библиотека для туров по продуктам
- [reactbits](https://reactbits.dev/)
- [justgage](https://github.com/toorshia/justgage) - создавать анимированные gauge-индикаторы для дашбордов
- [pqoqubbw](https://github.com/pqoqubbw/icons) - анимированные иконки
